# Planos

Ideias combinadas que ainda não foram feitas.

## Livro de missões (tutorial completo do pack)

**Objetivo:** um livro de missões em português, dentro do jogo, que ensine a usar cada mod do pack
em detalhe, do primeiro dia até o fim, para quem nunca jogou com mods.

**Como deve ser**

- Uma trilha por mod ou grupo de mods (ver [mods.md](mods.md)), cobrindo todos os pontos que
  fizerem sentido: o que o mod faz, como fazer os primeiros itens, como evoluir e os truques
  menos óbvios.
- Ordem de progressão natural: primeiros passos (JEI, Jade, mapa, Waystones, Corpse) → baús e
  mochilas → ferramentas → Create (do moinho às fábricas) → dragões (Wyrmroost) → Aether →
  estruturas e biomas para explorar.
- Cada missão com objetivo verificável (pegar item, construir bloco, visitar bioma/estrutura,
  matar mob) e recompensa pequena que ajude o próximo passo.
- Texto curto e direto, com dicas de tecla (`R`/`U` no JEI, `W` no Ponder do Create).
- Apontar para o Ponder do Create em vez de repetir o que ele já explica com animação.

**Referências para estudar antes de escrever**

- Livros de missões de modpacks conhecidos com Create e vanilla+ (packs da linha "Create" e
  packs focados em iniciantes no Modrinth/CurseForge): estrutura das trilhas, tamanho das missões,
  recompensas.
- Guias oficiais e wikis de cada mod do pack.

**Ferramenta**

- Candidato: Odyssey Quests (está no Modrinth para NeoForge 1.21.1, então entra pelo pack).
- FTB Quests é o padrão dos modpacks, mas não está no Modrinth, e o `.mrpack`/packwiz só baixa
  de lá. Reavaliar se isso mudar.
- As missões ficam versionadas no repo (arquivos de configuração do mod) e chegam a todos pela
  atualização automática.

**Quando:** depois de fechar a lista de mods, para não reescrever missões a cada mudança.
